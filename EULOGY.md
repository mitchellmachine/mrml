# In memory of Terry A. Davis

Terry A. Davis demonstrated that one person could pursue a complete computing
system with unusual coherence, directness, and personal conviction. TempleOS
was inseparable from its author: compiler, kernel, shell, graphics, language,
and applications formed one understandable whole rather than a collection of
opaque layers.

MRML does not copy TempleOS and does not adopt its architecture or security
model. Its memory-safety rules, capability boundaries, microkernel isolation,
userspace services, VM compartments, accessibility requirements, and modern
hardware protections lead in a different technical direction. The inspiration
is narrower and enduring: important systems can still be understood, owned,
and built deliberately from first principles.

This project remembers Terry as a gifted programmer whose work challenged the
assumption that whole-system computing had become too large for an individual
to comprehend. That example is historical inspiration, not normative policy;
MRML's policy remains in `VALUES.md`, `docs/ENGINEERING_CONSTITUTION.md`, and the
security and architecture documents.
